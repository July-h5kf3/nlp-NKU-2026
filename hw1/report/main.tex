\begin{abstract}
本实验在 NYT 三类新闻分类（体育、政治、商业）上比较三类文本表示：词袋模型、静态词向量和预训练语言模型 BERT。所有方法共用同一个分层随机划分（训练、验证、测试为 80\%/10\%/10\%），在 1152 篇测试文档上报告 Accuracy 与 Macro-F1。按作业要求的六个设置，测试集结果依次为：二元词袋 0.9896 / 0.9741，词频词袋 0.9913 / 0.9779；GloVe（100 维）0.9852 / 0.9646，在 AG News 上训练的 Word2Vec \pmstd{0.9760}{0.0005} / \pmstd{0.9415}{0.0016}，只在 NYT 训练集上训练的 Word2Vec \pmstd{0.9806}{0.0018} / \pmstd{0.9524}{0.0037}；bert-base-uncased 在最大长度 64、训练 3 个 epoch 后为 \pmstd{0.9826}{0.0009} / \pmstd{0.9615}{0.0006}（Word2Vec 与 BERT 为 3 个随机种子的均值 $\pm$ 标准差）。在作业设置下，词频词袋最好；BERT 只读入每篇新闻开头的 62 个子词，低于看到全文的词袋和 GloVe。额外实验中，将 BERT 的最大长度增加到 256 和 512 后，其均值超过词频词袋。逐类指标显示，各方法的错误主要集中在商业与政治两类之间。学习曲线和截断策略两组额外实验还显示，词袋在各训练规模下均不弱于 BERT（长度 64），而文档开头是 BERT 最有效的输入片段。
\keywords{文本分类；词袋模型；Word2Vec；GloVe；BERT；Logistic Regression}
\end{abstract}

\section{实验目的}

本实验在同一个文本分类任务上比较词袋模型、以 Word2Vec 与 GloVe 为代表的静态词向量，以及预训练语言模型 BERT。前两类表示配合 Logistic Regression 分类，BERT 按微调流程训练，最后统一用 Accuracy 与 Macro-F1 评价。具体目标为：
\begin{enumerate}
  \item 理解不同文本表示的基本思想，完成文本分类的完整实验流程；
  \item 掌握 Logistic Regression 在文本分类中的使用；
  \item 掌握 Word2Vec、GloVe 等词向量的训练与使用；
  \item 熟悉 BERT 类预训练语言模型的微调；
  \item 比较各类表示的效果，并结合逐类指标与错误样例进行分析。
\end{enumerate}

\section{数据集与划分}

\section{方法}

\subsection{分类目标与 Logistic Regression}
\label{sec:objective}

设文档 $d$ 的表示为向量 $\mathbf{x}_d$。三类表示的区别只在 $\mathbf{x}_d$ 如何得到，最后一步相同：用线性层把表示映射为三个类别分数（logit）$z_1,z_2,z_3$，再经 Softmax 得到概率，
\begin{equation}
\label{eq:softmax}
z_j=\mathbf{w}_j^{\top}\mathbf{x}_d+b_j,\qquad
p_j=\frac{\exp(z_j)}{\sum_{k=1}^{3}\exp(z_k)},
\end{equation}
预测类别为 $\arg\max_j p_j$。

对词袋和静态词向量，分类器是多项 Logistic Regression。scikit-learn~\cite{pedregosa2011sklearn} 默认带 $\ell_2$ 正则项，训练目标为交叉熵加正则项：
\begin{equation}
\label{eq:lr}
\min_{W,\mathbf{b}}\;\sum_{i=1}^{n}-\log p_{y_i}(\mathbf{x}_i)+\frac{1}{2C}\lVert W\rVert_F^{2},
\end{equation}
其中 $y_i$ 为第 $i$ 篇训练文档的真实类别，$W=[\mathbf{w}_1,\mathbf{w}_2,\mathbf{w}_3]$，$C$ 为正则强度的倒数（默认 $C=1$）。求解器为 saga~\cite{defazio2014saga}。BERT 的分类头同样是式~\eqref{eq:softmax} 的线性层，损失为交叉熵，正则由 AdamW 的权重衰减~\cite{loshchilov2019adamw} 提供。

\subsection{词袋模型}

词袋模型把文档表示为固定词表上的向量，忽略词序，只保留词是否出现以及出现多少次。按作业要求比较以下两种表示，另外补充 TF-IDF 作为额外对照。记文档 $d$ 中词 $w$ 的出现次数为 $\mathrm{tf}(d,w)$：
\begin{itemize}
  \item \textbf{二元词袋（Binary BoW）}：$x_{d,w}=\mathbb{1}[\mathrm{tf}(d,w)>0]$，同一个词重复出现不改变对应分量；
  \item \textbf{词频（Word Frequency）}：$x_{d,w}=\mathrm{tf}(d,w)$，文档越长，各分量整体越大；
  \item \textbf{TF-IDF（额外）}：$x_{d,w}=\mathrm{tf}(d,w)\cdot\mathrm{idf}(w)$，其中 $\mathrm{idf}(w)=\log\frac{1+N}{1+\mathrm{df}(w)}+1$，$N$ 为训练文档数，$\mathrm{df}(w)$ 为包含 $w$ 的训练文档数；之后对每篇文档做 $\ell_2$ 归一化。
\end{itemize}
分词统一使用 NLTK~\cite{bird2009nltk} 的 \texttt{word\_tokenize}，标点和单字符词作为独立的词保留。词表与逆文档频率只在训练集上估计，验证集和测试集只做变换，词表大小为 127053。

\subsection{静态词向量}

静态词向量把每个词映射为一个固定的低维稠密向量，语义相近的词在向量空间中距离较近。记词 $w$ 的词向量为 $\mathbf{e}_w\in\mathbb{R}^{100}$。文档 $d$ 用与词袋相同的方式分词，保留词向量词表中存在的词 $w_1,\ldots,w_m$（重复出现的词按出现次数计入），文档向量取平均：
\begin{equation}
\mathbf{x}_d=\frac{1}{m}\sum_{i=1}^{m}\mathbf{e}_{w_i}.
\end{equation}
词表外（OOV）的词不参与平均；若 $m=0$ 则取零向量（本实验的测试集中没有出现这种情况）。分类器、划分和评价方式与词袋实验相同，结果差异只来自词向量的来源。

\textbf{GloVe}~\cite{pennington2014glove} 是基于全局共现统计的词向量。记 $X_{ij}$ 为词 $i$ 与词 $j$ 在窗口内的共现次数，GloVe 用加权最小二乘让词向量内积加偏置项拟合共现次数的\emph{对数}：$\mathbf{e}_i^{\top}\tilde{\mathbf{e}}_j+b_i+\tilde{b}_j\approx\log X_{ij}$。本实验直接使用公开的 glove.6B 100 维向量（在 Wikipedia 2014 与 Gigaword 5 上训练，词表 400000），不在 NYT 上更新。图~\ref{fig:glove} 是 GloVe 论文中说明其动机的例子：单独的共现概率难以区分相关与无关的上下文词，共现概率的比值则可以。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.62\textwidth]{glove_cooccurrence_table.pdf}
  \caption{GloVe 论文中的共现概率示例（60 亿词语料）。与 ice 相关的 solid 使比值远大于 1，与 steam 相关的 gas 使比值远小于 1，而 water、fashion 这类与两者都相关或都无关的词比值接近 1。GloVe 因此直接对共现统计建模。图片来源：Pennington et al., 2014~\cite{pennington2014glove}，表 1}
  \label{fig:glove}
\end{figure}

\textbf{Word2Vec}~\cite{mikolov2013efficient,mikolov2013distributed} 采用 skip-gram 结构：给定中心词，预测窗口内的上下文词，并用负采样代替对整个词表的 Softmax 归一化。本实验用 gensim~\cite{rehurek2010gensim} 自行训练两个模型，超参数相同（表~\ref{tab:hp}）：
\begin{itemize}
  \item \textbf{AG News 模型}：在 90000 篇 AG News 正文上训练，词表大小 25376；
  \item \textbf{NYT 模型}：\emph{只}在 NYT 训练集的 9215 篇正文上训练，词表大小 31657。验证集和测试集的正文不参与词向量训练，与 GloVe、AG News 模型处于同一条件。
\end{itemize}
作为消融，第~\ref{sec:emb} 节还报告了用 NYT 全部正文（含验证集和测试集）训练的模型，以衡量这种转导式泄漏的影响。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.72\textwidth]{word2vec_cbow_skipgram.pdf}
  \caption{Word2Vec 的两种结构：CBOW 用窗口内的上下文词预测中心词 $w(t)$，skip-gram 用中心词预测上下文词。本实验使用右侧的 skip-gram。图片来源：Mikolov et al., 2013~\cite{mikolov2013efficient}，图 1}
  \label{fig:word2vec}
\end{figure}

\subsection{预训练语言模型 BERT}

BERT~\cite{devlin2019bert} 是用掩码语言模型等任务预训练的双向 Transformer 编码器。文本先被切成 WordPiece 子词，每层自注意力同时读取左右两侧的上下文，因此同一个词在不同语境下的表示不同，这是它与静态词向量的根本区别。本实验使用 bert-base-uncased（12 层、12 个注意力头、隐藏维度 768、词表 30522），通过 Hugging Face Transformers~\cite{wolf2020transformers} 加载。图~\ref{fig:bert-overview} 展示了 BERT 先预训练、再在下游任务上微调的流程。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.95\textwidth]{bert_pretrain_finetune.pdf}
  \caption{BERT 的预训练与微调流程。微调时除输出层外沿用预训练的结构和参数；本实验是单文本分类，只在 \texttt{[CLS]} 位置的输出 $C$ 上接分类头。图片来源：Devlin et al., 2019~\cite{devlin2019bert}，图 1}
  \label{fig:bert-overview}
\end{figure}

输入序列以 \texttt{[CLS]} 开头、以 \texttt{[SEP]} 结尾。按作业要求，最大长度为 64，超出部分从末尾截断；这 64 个位置包含两个特殊符号，因此每篇新闻实际只保留开头的 62 个子词。\texttt{[CLS]} 的最后一层隐状态经过 BERT 的 pooler（全连接层加 tanh），再经 dropout 输入随机初始化的线性分类头，输出三个 logit。微调时分类头与全部预训练参数一起更新，训练 3 个 epoch。每个位置的输入向量由词元嵌入、句段嵌入和位置嵌入相加得到（图~\ref{fig:bert-input}）。

\begin{figure}[htbp]
  \centering
  \includegraphics[width=0.82\textwidth]{bert_input_representation.pdf}
  \caption{BERT 的输入表示：词元嵌入、句段嵌入与位置嵌入逐位相加。本实验的输入只有一段文本，句段嵌入均为 $E_A$；bert-base-uncased 只有 512 个位置嵌入，这也是其输入长度的上限。图片来源：Devlin et al., 2019~\cite{devlin2019bert}，图 2}
  \label{fig:bert-input}
\end{figure}

每个 epoch 结束后在验证集上计算 Macro-F1。本实验同时报告两个测试结果：（1）训练满 3 个 epoch 后的模型（作业要求的设置，下文记为“末轮”）；（2）验证集 Macro-F1 最高的 epoch 对应的检查点（下文记为“验证集最优”）。

\textbf{随机性。}数据划分的种子始终为 42。Logistic Regression 固定 \texttt{random\_state}，同一输入下结果确定，因此词袋和 GloVe 只运行一次。Word2Vec 的训练结果依赖随机初始化和负采样，BERT 依赖分类头初始化、dropout 和数据顺序，因此这两类方法各用 3 个随机种子（42、43、44）重复实验，报告均值 $\pm$ 样本标准差（$n-1$ 归一化）。BERT 用 \texttt{transformers.set\_seed} 同时固定 Python、NumPy 与 PyTorch（含 CUDA）的随机数；GPU 上的浮点运算仍可能带来极小的不确定性：用 \texttt{run\_all.sh} 完整重跑一次，词袋、GloVe、Word2Vec 以及最大长度 32、64 的全部 BERT 运行（含主结果表）与本报告的结果逐位一致，而最大长度 128 及以上的部分 BERT 运行会有数篇测试文档的预测不同，相应均值的变化小于种子间的标准差。

\textbf{实验环境。}所有实验在一台配有 8 张 NVIDIA H800（80 GB）的服务器上完成，BERT 每次只使用一张 GPU（驱动 570.124.06，CUDA 12.8），CPU 为 Intel Xeon Platinum 8468V。软件版本为 Python 3.12.13、PyTorch 2.11.0、Transformers 5.17.0、scikit-learn 1.9.1、gensim 4.4.0、NLTK 3.10.3、NumPy 2.5.3。运行时间方面，三种词袋的向量化与 Logistic Regression 拟合分别耗时 35.4、109.8、22.0 秒（saga 分别迭代 323、1851、50 次，均已收敛）；BERT 在最大长度 64 下训练 3 个 epoch（含每轮验证）约 48--56 秒，最大长度 512 约 210 秒。

\subsection{词袋模型}
\label{sec:bow}

两种必做的词袋表示都很强。词频的 Accuracy 比二元词袋高 0.17 个百分点（测试集上相差 2 篇文档），Macro-F1 高 0.38 个百分点。保留出现次数能区分“顺带提到一次”和“反复出现”的类别词，例如一篇偶尔提到 \emph{market} 的体育报道，与反复出现 \emph{market}、\emph{bank}、\emph{percent} 的商业报道。从 Logistic Regression 的权重看，二元词袋中商业类权重最大的词包括 \emph{company}、\emph{companies}、\emph{market}、\emph{bank}，政治类包括 \emph{state}、\emph{washington}、\emph{republican}、\emph{obama}，体育类包括 \emph{players}、\emph{league}、\emph{game}、\emph{team}，都是直观的类别标志词。额外对照的 TF-IDF（0.9896 / 0.9751）与二元词袋的 Accuracy 相同，在默认 $C=1$ 下没有超过词频。

词袋在本任务上的优势与已有文献一致。Joachims~\cite{joachims1998text} 指出，文本分类的特征维度很高但大多数特征都与类别相关，文档向量稀疏，而且多数文本分类问题线性可分，因此线性模型很适合词袋特征。Wang 和 Manning~\cite{wang2012baselines} 发现，在主题分类上，基于词袋（及二元组）的简单线性模型是很难超越的基线；fastText~\cite{joulin2017bag} 也表明，在 AG News 等新闻主题分类数据集上，基于 n-gram 词袋的线性模型与当时的深度模型精度相当。NYT 的三类划分同样以主题为主，类别几乎由用词决定，词袋表现最好并不意外。

\textbf{正则强度（额外）。}表~\ref{tab:bow-c} 给出用验证集选择 $C\in\{0.01,0.1,1,10,100\}$ 的结果。二元词袋和词频在 $C\ge0.1$ 时测试结果完全不变，正则强度基本不影响它们。二元词袋的验证集 Macro-F1 在 $C=0.01$ 时略高，但对应的测试 Macro-F1 反而下降到 0.9681，说明在每类只有约 144 篇的少数类验证样本上，这样小的差异很难可靠地区分不同设置。TF-IDF 特征经过 $\ell_2$ 归一化，数值尺度小，需要较弱的正则：$C=0.01$ 时模型把所有文档都判为体育类（Macro-F1 0.2857），验证集选出的 $C=100$ 在测试集上达到 0.9922 / 0.9812，是所有词袋设置中最高的。主结果仍按作业要求使用默认 $C=1$。

\subsection{静态词向量}
\label{sec:emb}

三种词向量中 GloVe 最好（0.9852 / 0.9646），在 NYT 训练集上训练的 Word2Vec 次之，AG News 上训练的 Word2Vec 最低。两个 Word2Vec 模型在 3 个种子之间的标准差为 0.05--0.18 个百分点（Accuracy），远小于它们与 GloVe 的差距，因此这一排序是稳定的。

表~\ref{tab:oov} 给出各词向量在 NYT 测试集上的覆盖情况。词级 OOV 率指测试集所有词中不在词向量词表里的比例，类型级 OOV 率指测试集中不同词形不在词表里的比例。覆盖率与分类效果的排序一致：GloVe 的词表最大，只有 1.95\% 的测试词找不到向量；AG News 模型的词表最小，且领域与 NYT 不完全相同（AG News 是短摘要，NYT 是长篇报道），5.76\% 的测试词和 60.24\% 的测试词形没有向量。未登录词无法为文档向量提供信息，覆盖率越低，可用的类别线索越少。此外，GloVe 在约 60 亿词的语料上估计共现统计，而两个 Word2Vec 模型的训练语料小几个数量级，向量质量也相应较差。

\textbf{NYT 词向量的泄漏消融。}原始代码用 NYT 的全部正文训练 Word2Vec，其中包括验证集和测试集的文本。虽然没有用到标签，但测试文本参与了表示学习。本次修订改为只用训练集训练，并把全部正文训练的版本作为消融。3 个种子下，全部正文版本为 \pmstd{0.9818}{0.0017} / \pmstd{0.9546}{0.0042}，仅训练集版本为 \pmstd{0.9806}{0.0018} / \pmstd{0.9524}{0.0037}：泄漏使词表从 31657 扩大到 35447、测试集词级 OOV 率从 2.46\% 降到 1.86\%，但两项指标只高出约 0.1 和 0.2 个百分点，与种子间的波动处于同一量级。这种泄漏带来的影响很小；为与 GloVe、AG News 模型公平比较，主结果仍采用仅训练集的版本。（修订前报告的单次结果为 0.9800 / 0.9506，与上述区间一致。）

与最好的词频词袋相比，GloVe 的 Accuracy 低 0.61 个百分点（7 篇文档），Macro-F1 低 1.33 个百分点。词袋为每个词保留独立维度，类别标志词可以直接进入线性分类器；平均词向量先把词压缩到 100 维，再对整篇近 800 个词取平均，少数关键的类别词会被大量通用词稀释。在本数据集类别用词差别明显的情况下，保留每个词的独立特征更有利于线性分类。

已有文献对平均池化的局限进行了讨论。Iyyer 等~\cite{iyyer2015deep} 表明，对词向量做无序平均再接深层网络，在情感和问答分类上就能与依赖句法结构的模型相当；Shen 等~\cite{shen2018baseline} 进一步发现，对主题分类而言词序信息的贡献很小，简单的平均或最大池化就能接近 CNN 和 LSTM，词序在情感分析中更重要。本任务是主题分类，因此丢失词序不是主要瓶颈，更关键的是\emph{均匀}平均：每个词的权重只由出现次数决定，高频的通用词主导了文档向量。Arora 等~\cite{arora2017simple} 提出按词频对词向量加权并去除公共主成分，能改善平均词向量的效果。相比之下，词袋上的 Logistic Regression 为每个词学习独立的权重，相当于有监督地完成了这种加权。

领域差异也影响静态词向量。AG News 由新闻标题加一两句摘要组成，NYT 则是平均近 800 词的长篇报道，用词分布不同。Gururangan 等~\cite{gururangan2020dont} 对预训练语言模型的研究表明，表示学习语料与目标领域越接近，下游任务效果越好。本实验的静态词向量也呈现同样的规律：NYT 模型的训练文档数只有 AG News 的约十分之一，结果仍高于 AG News 模型，测试集 OOV 率也更低（表~\ref{tab:oov}）。

在作业设置下，BERT 的 Accuracy（\pmstd{0.9826}{0.0009}）低于词频词袋 0.87 个百分点（约 10 篇文档），也略低于 GloVe，但高于两个 Word2Vec 模型。原因在于输入长度：BERT 只看到每篇新闻开头的 62 个子词，而测试集文档的子词数中位数约为 889，词袋和词向量则使用全文。新闻的导语常常是场景描写或人物故事，类别线索可能要到后文才出现（见第~\ref{sec:error} 节）。即便如此，BERT 用不到全文 10\% 的内容就超过了基于全文的 Word2Vec，说明上下文相关的预训练表示信息密度更高。

截断是 BERT 处理长文档的通行做法：自注意力的计算量和显存随序列长度二次增长，位置嵌入也只有 512 个，Longformer~\cite{beltagy2020longformer} 等长文档模型正是为突破这一限制而提出。Park 等~\cite{park2022efficient} 在多个长文档分类数据集上的比较发现，只保留前 512 个 token 的 BERT 基线往往不逊于 Longformer 等更复杂的模型，说明很多文档的关键信息集中在开头；但当关键信息出现在后文时，挑选后文片段的方法更有优势。第~\ref{sec:truncation} 节的截断策略实验在 NYT 上检验了这一点。

\subsection{额外实验：BERT 的截断策略}
\label{sec:truncation}

主实验只保留文档开头（head）。参照 Sun 等~\cite{sun2019fine} 的做法，再比较两种策略：只保留结尾（tail），以及同时保留开头和结尾（head+tail）。head+tail 按 Sun 等在长度 512 时使用的比例（开头 128、结尾 382 个子词）分配，即开头约占正文预算的四分之一：长度 64 时为开头 16 + 结尾 46 个子词，长度 128 时为开头 32 + 结尾 94 个子词。其余设置不变，每种组合用 3 个种子，结果见表~\ref{tab:truncation}。

\subsection{错误分析}
\label{sec:error}

比较词频词袋与 BERT（长度 64、种子 42、末轮）在测试集上的预测：词袋错 10 篇，BERT 错 21 篇，两者同时出错 4 篇；有 17 篇是 BERT 错而词袋对。逐篇查看这 17 篇，主要有两类情况：
\begin{itemize}
  \item \textbf{导语不含类别线索。}例如一篇体育类报道开头讲述一对夫妇从夏威夷度假回来、丈夫出现痴呆症状的经过，前 62 个子词里没有任何体育词汇，BERT 判为政治；直到后文才交代主人公曾在 \emph{n.f.l.} 担任七个赛季的锋线球员，并出现 \emph{football}、\emph{coach} 等词。又如一篇体育类专栏开头写瑞典的咖啡文化，BERT 判为商业，直到后半篇才说明作者是在瑞典俱乐部效力的足球运动员，\emph{team}、\emph{coach}、\emph{season} 等词也都出现在后半篇。
  \item \textbf{导语中的误导性线索。}一篇讲信用卡旅行福利的商业类文章，开头用 n.c.a.a.\ 男篮锦标赛的竞猜作比喻，BERT 判为体育。
\end{itemize}

此外，还有几篇商业类报道开头即是国会、预算或财政部的内容（例如财政部就债务上限向国会发出警告），BERT 判为政治。这类文章处在两类的边界上，词袋方法同样容易在商业和政治之间混淆（表~\ref{tab:perclass}）。上述样例印证了第~\ref{sec:bert} 节的分析：长度 64 的主要损失来自截断，而不是 BERT 表示能力不足。

\section{结论}

本实验在同一 NYT 划分上比较了词袋、静态词向量和 BERT 三类文本表示。在作业要求的设置下，词频词袋取得最好的结果（Accuracy 0.9913，Macro-F1 0.9779），GloVe 次之，BERT（最大长度 64）和两个 Word2Vec 模型随后。这一结论依赖于本任务的两个特点：三类新闻用词差别明显，且文档长度远超 BERT 的输入上限。主要发现如下：
\begin{itemize}
  \item \textbf{词袋保留独立词特征。}类别标志词在词袋中各占一维，可以被线性分类器直接利用；平均词向量会把这些信号稀释在近 800 个词中。保留出现次数的词频表示略好于二元表示。
  \item \textbf{词向量的质量与覆盖率决定效果。}GloVe 词表最大、测试集 OOV 率最低，结果最好；AG News 模型受领域差异和词表较小的影响，结果最差。NYT 词向量即使见过测试正文，提升也只有约 0.1 个百分点，与种子波动相当。
  \item \textbf{BERT 的瓶颈是输入长度。}在长度 64 下，BERT 只读到开头的 62 个子词，仍超过基于全文的 Word2Vec；随着最大长度增加，其结果持续提升，在 256 和 512 时超过词频词袋。错误样例表明，长度 64 时的多数额外错误来自导语缺少类别线索。
  \item \textbf{错误集中在商业与政治之间。}体育类几乎没有错误，Macro-F1 的差距主要由商业与政治两类之间的混淆决定。
  \item \textbf{额外实验。}学习曲线显示，只有 921 篇训练文档时 GloVe 与词袋相当，数据越多词袋的优势越明显，长度 64 的 BERT 在各规模下都低于词袋；截断策略实验表明，文档开头是最有效的输入片段，长度 128 时同时保留开头和结尾的 Macro-F1 高约 0.35 个百分点，但差距在噪声范围内。
\end{itemize}

\textbf{不足与改进方向。}（1）BERT 在长度 512 时仍有 931 篇测试文档被截断，长文档可尝试分段编码再聚合各段的 \texttt{[CLS]} 表示，或使用 Longformer~\cite{beltagy2020longformer} 等长文档模型；（2）平均词向量可改为 TF-IDF 或 SIF~\cite{arora2017simple} 加权平均，减弱常见词的稀释作用；（3）可在损失函数中按类别加权，观察 Macro-F1 是否有所改善；（4）BERT 的学习率、批大小等只取了一组设置，较长输入在 3 个 epoch 内尚未饱和，后续可扩大参数搜索范围；（5）测试集中少数类各只有约 144 篇，方法之间差异通常只涉及数篇文档，更稳健的比较需借助更多随机种子或交叉验证。
